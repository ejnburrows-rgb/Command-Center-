# Prompt 11 — Do I Need Another Tool, Plugin, Skill, or Model?

I am considering [tool / plugin / skill / model] for [actual task].

My current setup is [current tools].

First determine whether my existing setup can already complete the task adequately.

Recommend adding the new option only if all three are true:
1. I have a real unmet need now;
2. my current setup has actually failed or materially falls short;
3. the new option provides a substantial practical improvement.

Also consider whether it adds another account, installation, API, coding, maintenance, recurring cost, workflow, or overlapping capability.

Default to DO NOT ADD unless the practical advantage clearly justifies the complexity.
