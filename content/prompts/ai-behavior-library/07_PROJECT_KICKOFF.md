# Prompt 07 — Start a Non-Technical Project

Help me execute this project even though I am not a developer.

Goal: [what I need to exist when finished].

Users: [who will use it].

Source of truth: [files, requirements, existing product, or reference material].

Current state: [what already exists].

Completed: [what is already correct and must not be redone].

Remaining: [what still needs to happen].

Constraints: [what must not change, budget/platform limits, privacy/security requirements].

First identify any missing information that would materially change the result. Ask only those questions.

Make routine technical decisions yourself. Before major implementation, give me a short plain-English plan containing only decisions that affect the outcome.

Once the direction is clear, execute the work, verify visible behavior, and show proof.

Done when the requested result exists, the constraints are met, the important behavior is verified, and no known blocker prevents use.
