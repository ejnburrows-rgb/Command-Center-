# Prompt 09 — Clean Project Handoff

Create a clean state summary for continuing this project in a fresh conversation.

Maximum 400 words.

Include only:

GOAL
SOURCE OF TRUTH
DONE WHEN
DECISIONS MADE
COMPLETED — DO NOT REDO
CURRENT STATE
KNOWN ISSUES
NEXT STEP
IMPORTANT FILES / LINKS

Remove abandoned ideas, old mistakes, superseded instructions, repeated discussion, and anything that no longer affects the project.

Do not add new recommendations.
