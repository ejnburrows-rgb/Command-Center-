# Prompt 13 — Prompt Rewriter

Turn my rough request into the smallest reliable prompt that preserves my actual goal.

Remove repetition, emotional filler, irrelevant history, unnecessary technical detail, obsolete prompt tricks, redundant rules, and unnecessary personas.

Add only what materially improves the result.

Use only the sections needed:
TASK
CONTEXT
CONSTRAINTS
SOURCES / VERIFY
OUTPUT
DONE WHEN

For simple tasks, keep it to one or two sentences.

For current or accuracy-sensitive tasks, add verification.

For execution tasks, use action verbs and tell the AI to perform the work.

Return only:

READY PROMPT

followed by the rewritten prompt.
