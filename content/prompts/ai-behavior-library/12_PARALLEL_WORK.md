# Prompt 12 — Parallel Work

Act as the coordinator for this task.

Divide the objective into a maximum of 3 jobs that can be done independently in parallel.

Do not separate tasks that depend on each other. Do not assign multiple workers to modify the same part of the project at the same time.

For each job define:
- objective;
- information needed;
- expected result;
- done condition.

When the results return, compare them, resolve conflicts, and produce one integrated final result.

If parallel work would create more coordination than time savings, use one workflow instead.
