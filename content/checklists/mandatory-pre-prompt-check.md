---
title: "Mandatory Pre-Prompt Check"
project: global
created: 2026-07-11
updated: 2026-07-12
---

Before delivering any coding-agent prompt, every box must be checked:

- [ ] Produces a tangible finished artifact (not a report)
- [ ] Removes the current top-priority blocker
- [ ] Is not already completed, running, or assigned elsewhere
- [ ] The receiving agent can access the private repo / required files
- [ ] Its file lane does not overlap with active agents
- [ ] The output is worth paying for at the full estimated cost
