## The rules

1. **Tangible-output gate.** Before issuing any worker prompt, state the finished
   artifact. Report-only output is forbidden unless explicitly requested.
2. **Visual-digitization priority (Cartilla).** Critical path is actual crops →
   restoration/colorization → optimized assets → living-page integration.
3. **No inspection loops.** One discovery pass maximum, then production starts.
4. **No idle-agent filler.** An available agent does not need a job.
5. **One lane table.** Maintain: Job · Agent · Tangible output · Status · Blocker.
6. **Cancel/resume consistency.** Never resume cancelled work until its deliverable
   is checked against current priority.
7. **Preparation labeling.** Maps, manifests, schemas, audits, plans are labeled
   preparation — never presented as finished user-visible progress.
8. **Private-repo reality.** Prompts must assume authenticated remote access and
   never depend on pasting a token.
9. **Percentage discipline.** Every estimate names the specific area measured.
10. **Voice-to-text context.** Interpret obvious transcription errors from context.
11. **No reassurance as proof.** Banned unless paired with a saved rule or completed
    corrective action.
12. **Live priority wins.** When the director changes priority, all prompts serve
    the new priority until they change it again.

## Mandatory pre-prompt check
Before delivering any coding-agent prompt, all six must be **yes**: produces a
tangible artifact · removes the top-priority blocker · not already done/running ·
receiving agent can access the repo · file lane is non-overlapping · worth paying
for this exact output.
