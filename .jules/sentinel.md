## 2023-11-23 - Timing attack vulnerability in passphrase comparison
**Vulnerability:** The authentication route (`app/api/auth/route.ts`) was using a simple string comparison (`body.passphrase !== phrase`) to check the provided passphrase against the secret passphrase. This exposes the application to timing attacks, where an attacker can deduce the passphrase by measuring the time it takes for the comparison to fail.
**Learning:** Simple string comparison operators in JavaScript/TypeScript (like `===` or `!==`) fail as soon as a mismatch is found. The time taken to return a result is proportional to the number of matching characters at the beginning of the strings. This is a critical security vulnerability when comparing sensitive secrets.
**Prevention:** Always use constant-time comparison algorithms when comparing passwords, tokens, or passphrases. In Node.js, `crypto.timingSafeEqual()` from the `node:crypto` module should be used. Ensure both values are converted to Buffers of the same length (e.g., by hashing them first if their lengths might differ) before comparison.
